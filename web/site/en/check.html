Check any node

Paste an address — the server will open a tunnel through it and make an HTTP request. The result shows whether the node is alive, how long the connection took, and which address the request came from.

Examples:

Enter an address and start the check. The result describes only this moment: a minute later the node may already be unavailable.

The check runs from the PoolNet server, not from your network — the node sees the server's address and latency. Private and service addresses are not checked.

What the verdict means

One HTTP request through the proxy to an echo server. The response is considered successful if the tunnel opened and the request returned a page.

alive
the tunnel opened, the request went through
failed
handshake failure, timeout or HTTP error
exit address
the address seen by the echo server
