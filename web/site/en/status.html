How to read these numbers

FUNNEL

How many passed verification

The values show how many addresses passed each verification stage in the current run.

POOL

Available nodes

"Pool after publication" means the nodes available right now: VPN configurations and list output are built from them.

DATABASE

Re-checked on every run

"Total nodes in the database" means nodes verified at least once. Every run re-checks them from scratch.
