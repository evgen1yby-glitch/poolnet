Проверить любой узел

Вставьте адрес — сервер откроет туннель через него и выполнит HTTP-запрос. Результат покажет, живой ли узел, сколько заняло соединение и с какого адреса пришёл запрос.

Примеры:

Введите адрес и запустите проверку. Результат описывает только этот момент: через минуту узел может быть уже недоступен.

Проверка идёт с сервера poolnet, а не из вашей сети — узел видит адрес и задержку сервера. Приватные и служебные адреса не проверяются.

Что значит вердикт

Один HTTP-запрос через прокси к эхо-серверу. Ответ считается успешным, если туннель открылся и запрос вернул страницу.
