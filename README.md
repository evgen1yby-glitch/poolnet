# evilgate

Единая платформа **evilgate** (evilgate.online): открытая прокси-база
(HTTP/SOCKS4/SOCKS5) и VPN-конфигурации (vless/ss/vmess/trojan) — два пула,
один стандарт проверки реальными соединениями, открытые данные и статусы.
Объединяет два прежних проекта: `hub` (freevpn, контрольная плоскость VPN)
и `pool` (open-proxy-pool, движок прокси-базы).

## Структура

- `web/site/` — сайт платформы (index, vpn, proxy, verify, premium, status).
- `hub/` — контрольная плоскость VPN-пула: сбор из публичных источников,
  проверка в 6 этапов, публикация, Telegram-бот. Python 3.11, FastAPI, aiogram.
  Лицензия: AGPL-3.0.
- `pool/` — движок прокси-базы: 189+ источников, дедупликация, проверка,
  benchmark источников, публикация JSON/TXT. Node ≥20.11, TypeScript.
  Лицензия: MIT.

План объединения: см. `PLAN.md`. Репозиторий в подготовке к публикации
на GitHub (данные прогонов и секреты в git не попадают).
